# Game switch logos

Drop your own logo images here and the Pokémon / One Piece switch will show them instead of text:

- `pokemon.png`
- `one-piece.png`
- `pfp.png` (optional — your profile pic; otherwise your Twitch pic is used)

Transparent PNGs about 300×100 look best. If a file is missing, the switch just shows the text label.
